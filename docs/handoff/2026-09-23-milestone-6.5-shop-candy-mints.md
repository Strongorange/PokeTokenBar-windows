## Decision Needed at Start (confirm with user before scaffolding)
- Difficulty settings storage: macOS keeps growth/shop difficulty in
  UserDefaults because it is a preference, not progression. Windows options:
  1. `settings.json` under `%LOCALAPPDATA%\PokeTokenBar\` owned by a small
     Platform.Windows settings service — recommended; keeps difficulty out of
     the save so imported saves never change local difficulty (macOS parity).
  2. Inside `CompanionState` — simpler wiring but imports/exports difficulty,
     macOS deliberately avoids this.
  Ask the user; option 1 matches macOS semantics.
- UI surface: extend the Game tab with a shop section (list + buy buttons +
  bag + use buttons) vs a third tab. Recommend one Game tab with sections
  while it fits; split only when cramped.
- Notifications: macOS fires user notifications on evolve/graduate/hatch and
  would on shop events. Windows toasts need `Microsoft.Toolkit.Uwp.Notifications`
  or similar. Recommend deferring notifications to M7 hardening unless the
  user wants them now.
- Egg purchase (`buyEgg`) discards the active mon but leaves a *released*
  `DexEntry` (macOS `releasedDexEntry`). Port as-is? (Recommend yes — the dex
  is a permanent record.)

## Hard-won Context
- Run/test: `dotnet test PokeTokenBar.Windows.slnx` (~2s, 260 tests) — wrong
  file error `MSB1009` if you type `.sln`.
- PowerShell traps hit while writing the snapshot generator (cost ~30 min):
  retry loops need `break` after success or every iteration emits multiple
  objects; functions returning a `JsonArray` get ENUMERATED into child nodes
  (wrap returns with `,`); array literals `@(a, $arr)` FLATTEN nested arrays —
  build `System.Text.Json.Nodes` trees directly; a subtree returned by
  `Find-Node` still has its parent — `DeepClone()` before re-parenting; a
  ternary inside an interpolated string hole needs parentheses (C# and PS).
- PokéAPI quirks: Manaphy (490) and Phione (489) share evolution chain 250
  whose root is NOT the requested base — the script re-roots at the base and
  falls back to a single-node tree when the base is absent from its chain.
  Chains of ≤649 species include >649 members (Sylveon 700 etc.);
  `EvoLine.KeepingAnimatedSprites` filters them at load (Eevee ends with 7
  branches, not 8).
- `Assert.Throws<T>` requires an EXACT exception type match —
  `SaveTransfer.Decode` on garbage throws `JsonReaderException`, use
  `Assert.ThrowsAny<JsonException>`.
- Baseline refresh applies NO usage — first-apply expectations in tests are
  zero, not the map sum (messed up three test calcs before).
- The hatch check must run on EVERY apply (even no-delta refreshes) — an
  imported ready egg or externally-set `EggUsage` hatches on the next refresh
  even when the ledger is unchanged. Early-return paths in `ApplyUsageCore`
  must fall through to `HatchIfReady()`.
- Read `PendingUnownForm` BEFORE clearing `PendingHatchID`/`PendingUnownForm`
  in `HatchIfReady` (locals keep values but the state fields do not).
- Engine smoke trick: `dotnet run file.cs` with `#:project <absolute path to
  csproj>` drives the real engine against real state (export/import) without
  the WPF app; AppLog is process-global so such runs write to the real
  diagnostics log.
- WPF name traps (unchanged): `App : System.Windows.Application` fully
  qualified; `using System.IO;` for `Path`.
- AppLog tests share one xUnit collection per test project
  (`Diagnostics.Configure/Read` helpers).
- Single-flight semantics of `UsageRefreshService` are unaffected — engine
  hooks live in `App`, not inside the service.
- Records containing `List<T>` do not get structural equality.
- Normal and unrelated: git CRLF warnings; `docker-desktop` in `wsl -l -v`;
  SSH trap if push denied (`ssh-add -d <key>; ssh-add <key>`, verify
  `ssh -T git@github-personal` greets `Strongorange`).
- Already tried and rejected: file watchers over the WSL boundary, live
  PokeAPI at runtime (snapshot chosen), parsing `wsl.exe -l` output.

## Open Risks
- Save/versioning: schema 2 has no difficulty fields (by design if option 1
  is chosen) — document that difficulty lives beside, not inside, the save.
- RNG consumption order changes when candy use routes through `ApplyGrowth` —
  keep `PickPlannedChild` rolls inside the shared growth loop only.
- `rareCandyStageCosts` mutates a copied `MonState` stage index while
  computing thresholds — port the copy trick; do not mutate the live mon.
- Shop button spam from the UI is single-threaded via the dispatcher but the
  engine lock is reentrant on one thread — fine for now, do not add
  engine->engine reentry from `Changed` handlers.
- Watch save size: `MaxFileBytes` 8 MiB is generous; inventory/candyGrantTier
  add trivial volume, dex names dominate.
- Floating pet (M7) will need sprite assets and light/dark awareness — do not
  couple shop UI to future sprite hooks.
